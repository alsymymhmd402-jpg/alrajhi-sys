# مشروع Android لتطبيق «مراسلة المؤسسة»

هذا المشروع يغلف **تجربة العميل فقط** داخل تطبيق Android باستخدام Capacitor. يبدأ التطبيق في صفحة `/client/start` الآمنة؛ يدخل العميل رابط الدعوة أو رمزه لفتح مساحته الخاصة، ولا يعرض غرفة العمليات أو بيانات المالك.

## طبيعة الاتصال

تظل المحادثات والملف وحالة الطلب متصلة بالموقع المنشور عبر الإنترنت. لذلك يتطلب التطبيق اتصالاً بالشبكة، ولا يخزن أسراراً أو مفاتيح API داخله.

## أوامر البناء

```bash
pnpm install
pnpm sync
pnpm build:debug
```

ينتج APK التجريبي عادةً في `android/app/build/outputs/apk/debug/app-debug.apk`. وللنشر في متجر Google Play يلزم مفتاح توقيع Android يملكه صاحب المؤسسة؛ لا يُنشأ أو يُحفظ مفتاح رسمي في هذا المشروع.
