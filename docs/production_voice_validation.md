# تدقيق النسخة المنشورة — تكامل الصوت وروابط الدعوة

تم التحقق على النطاق المنشور من غرفة العمليات ومن صفحة روابط الدعوة بعد صدور الإصدار `a0742f2f`.

| نقطة التحقق | النتيجة |
|---|---|
| زر «إنشاء رابط عميل» في رأس غرفة العمليات | ينقل إلى `/dashboard/invitations?create=1`. |
| بطاقة «رابط جديد لعميل» | تنقل إلى نموذج إنشاء الدعوة نفسه. |
| واجهة الهاتف بعرض 375px | يبقى زر «إنشاء رابط عميل» ظاهراً في أعلى غرفة العمليات، مع بقاء بطاقة الرابط الجديد قابلة للوصول. |
| اختيار الصوت عند إنشاء الدعوة | يظهر الصوت الافتراضي وخيارات Adam وKarim. |
| استقلال الصوت بين رابطين | ظهر رابط «عميل صوت Adam» بصوت Adam ورابط «عميل صوت Karim» بصوت Karim. |
| حماية المفتاح | تعرض لوحة الحالة اسم الموفر فقط، من دون أي مفتاح أو قيمة سرية. |

يبقى اختبار التحويل الصوتي الفعلي معلقاً على توفر رصيد ElevenLabs. عند إعادة المزود للحالة `402` يستمر الاتصال بالصوت الطبيعي وتظهر رسالة الفشل للمشغل.
