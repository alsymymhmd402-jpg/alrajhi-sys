# مواءمة أساس التطبيق مع منصة Voice Circle

تمت مراجعة الحزمة المقدمة كمصدر لتدفقات خدمة التواصل. يحتوي الأساس على بنية تطبيق مراسلة أعمال متعددة اللغات، بما في ذلك موارد عربية وبنية موجهة للاتصالات. ستعيد منصة Voice Circle بناء تدفقات الدعم المطلوبة كتطبيق ويب مستقل، ولا تعيد استخدام شيفرة الحزمة أو علاماتها أو وسائطها.

| تدفق الخدمة المطلوب | المقابل في Voice Circle |
|---|---|
| استقبال رسالة من عميل | رابط دعوة آمن وصفحة ضيف بلا تسجيل دخول |
| متابعة محادثة العميل | محادثة محفوظة وحالات مفتوحة وقيد المعالجة ومغلقة |
| تواصل فريق الدعم | لوحة مالك مقيدة بالصلاحيات مع إشعارات وسجل عملاء |
| الاتصال الصوتي | مكالمة WebRTC مباشرة بين المالك والضيف عبر خدمة إشارات حية |
| بديل خدمة الدعم البشرية | جلسة صوتية قصيرة العمر لوكيل ElevenLabs تدار من الخادم |
| استمرار الخدمة | روابط دعوات قابلة للإبطال، أرشفة، وسجل مكالمات وجلسات |

هذه المواءمة تبقي تجربة العميل بسيطة ومألوفة، لكن ببنية مستقلة وآمنة تناسب تشغيل الويب.
