# جرد وظائف غرفة العمليات

يوثق هذا الملف عناصر الاستخدام الأساسية في **Voice Circle** ونتيجة التحقق العملي لها. يميّز الجرد بين وظائف تحتاج إلى جلسة عميل حية، وبين وظائف تعمل مباشرة من غرفة العمليات.

| المسار أو القسم | الإجراء المرئي | النتيجة المتوقعة | حالة التحقق |
|---|---|---|---|
| `/` غرفة العمليات | زر «إنشاء رابط عميل» والبطاقة السريعة | يفتح صفحة الدعوات مع التركيز على حقل اسم العميل | متحقق تفاعلياً في بيئة التطوير |
| الشريط العلوي للهاتف | زر «رابط عميل» | يفتح إنشاء الرابط من أي صفحة إدارية | متحقق بصرياً على الهاتف؛ يُعاد فحصه بعد النشر |
| `/dashboard/invitations` | «إنشاء رابط العميل» | ينشئ رابطاً للعميل ويظهر حقل النسخ والمشاركة والفتح | متحقق عملياً |
| `/dashboard/invitations` | نسخ، مشاركة، فتح، إبطال، حذف | نسخ الرابط أو مشاركته أو فتح بوابة الضيف أو تغيير حالته أو حذفه | متحقق عملياً برابط اختبار |
| `/invite/:code` | متابعة ثم إرسال الطلب | ينشئ جلسة عميل وينتقل إلى `/chat/:publicId` | متحقق عملياً |
| `/dashboard/contacts` | فتح ملف العميل و«فتح محادثته» | يفتح المحادثة المطابقة للعميل المحدد | متحقق عملياً |
| `/dashboard/requests` | تغيير الحالة | يحفظ حالة الطلب الجديدة ويحدّث القائمة | متحقق عملياً |
| `/dashboard/chats` | فتح، أرشفة، اتصال، إرفاق، إرسال | يدير المحادثة؛ الاتصال يعرض حالة عدم اتصال العميل عند غياب جلسة حية | متحقق للأرشفة والاتصال؛ الرسائل والمرفقات مغطاة بالاختبارات |
| `/dashboard/settings` | حفظ إعدادات المالك | يحفظ الحقول ويظهر إشعار نجاح ثابت داخل الصفحة | متحقق عملياً |
| `/dashboard/calls` | سجل المكالمات | يعرض المكالمات والحالات بما فيها المكالمة الفائتة | متحقق بالاختبارات والواجهة |
| Voice AI والنماذج | عرض حالة المزود | يعرض `NOT CONFIGURED` عندما لا يوجد مزود صوتي حقيقي | متحقق؛ لا توجد وظيفة وهمية |

> لا تتطلب غرفة العمليات تسجيل دخول في النسخة الحالية، وفق قرار المالك. تبقى المحادثة كضيف مقيدة برابط دعوة صالح وجلسة خادم.
